## Cowork scheduled tasks

- `daily-aetherbot-analysis` — disabled (description updated 2026-05-13)

## What is NOT touched by Cowork

- LaunchAgent plists that may already be loaded into `launchctl` from
  `~/Library/LaunchAgents/` — user must `launchctl bootout` them.
- The live trader `~/bot.py` and its `aetherbot_logger.py` watchdog process
  on whichever Mac is running it (this host and/or Mini). User must `pkill`.
- Kalshi account state (positions, resting orders) — user must cancel.

## To re-enable

Remove every `AETHERBOT KILL-SWITCH 2026-05-13` block and restore plist
filenames. Do this only with explicit approval.
